🛠️ Installation du Launcher

1️⃣ Décompresser le dossier

VibeLauncher.zip

2️⃣ Ajouter les mods

Créer la structure suivante :

mods/
├── 1.9.4/
│   ├── OptiFine_1_9_4_HD_U_H5.jar
│   ├── vibemod_1_9_4.jar
│   └── BetterFps.jar
├── 1.10.2/
├── 1.11.2/
├── 1.12.2/
└── ...

3️⃣ Installer les dépendances

npm install

4️⃣ Lancer le launcher

npm start

🖥️ Compiler en .EXE

npm run build

Le fichier sera dans :

dist/
